健迹 · 个人健康助手 - 使用说明
================================

一、本地运行（无需联网）
--------------------------------
方式1（最简单）：双击 index.html，用浏览器打开即可使用。

方式2（本地服务器）：
  1. 进入本文件夹，在地址栏输入 powershell 回车
  2. 执行命令：python -m http.server 8080
  3. 浏览器访问 http://127.0.0.1:8080

二、部署公网链接（Netlify Drop，约1分钟）
--------------------------------
  1. 打开网址：https://app.netlify.com/drop
  2. 把本文件夹（解压后的整个文件夹）直接拖进网页虚线框
  3. 等待几秒，会自动生成一个 https://xxx.netlify.app 的公开链接
  4. 注册免费账号可保留链接并自定义名称，不注册链接为临时性质

三、功能说明
--------------------------------
· 概览：今日状态、近7天指标均值、最近记录、快速入口
· 健康记录：手动录入 / AI文字提取（本地规则）/ OCR模拟，草稿核对后保存
· 趋势回顾：7/14/30天指标曲线图，含数据缺口标注
· 就诊准备：自动生成可编辑的就诊自述卡，支持浏览器打印
· AI 助手：默认本地规则引擎（离线可用）；
  在「云端 AI 设置」中填入自己的 API Key
  （支持 DeepSeek / 通义千问 / Kimi 等 OpenAI 兼容接口）
  可升级为大模型问答，Key 仅保存在本机
· 服药管理：服药计划 + 每日打卡日历
· 数据与隐私：所有数据保存在浏览器 localStorage，可导出 JSON / 清空

四、注意事项
--------------------------------
· 数据保存在当前浏览器中，更换浏览器或电脑后数据不互通
  （可在「数据与隐私」页导出 JSON 备份）
· 清除浏览器缓存/网站数据会导致记录丢失，请先导出备份
· 本工具仅用于个人数据整理，不构成医疗建议
